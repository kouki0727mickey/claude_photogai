# claude_photogai

サムネイルやイラストを作るための、ブラウザで動く画像編集アプリ。Claude と一緒に開発している。
目標は「Photoshop の主要機能を、自分が使う分だけ」。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー（http://localhost:5173）
npm run build    # 型チェックと本番ビルド（dist/）
```

main に push すると、GitHub Actions で GitHub Pages に公開される（リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく）。

## できること（v0.1）

| 分類 | 機能 |
|---|---|
| ファイル | 新規（YouTube サムネイル・正方形・縦長などのプリセット）、画像を開く、プロジェクトの保存・読み込み（`.photogai.json`）、PNG / JPEG 書き出し |
| 画像の追加 | ボタン、ドラッグ＆ドロップ、クリップボードからの貼り付け |
| ツール | 移動、ブラシ（筆圧対応）、消しゴム、塗りつぶし（許容範囲つき）、四角形、楕円、文字、スポイト |
| 文字 | フォント 4 種、大きさ、色、太字、縁取り、影。後から編集でき、ラスタライズも可 |
| レイヤー | 追加・複製・削除・並べ替え・下と結合、表示・非表示、不透明度、描画モード 16 種 |
| 補正 | 明るさ、コントラスト、彩度、色相 |
| 操作 | 元に戻す・やり直す（50 回）、拡大縮小、スクロール |

### ショートカット

| キー | 動作 |
|---|---|
| V / B / E / G / U / O / T / I | 移動 / ブラシ / 消しゴム / 塗りつぶし / 四角形 / 楕円 / 文字 / スポイト |
| `[` / `]` | ブラシを細く / 太く |
| Space + ドラッグ、中ボタンドラッグ | 表示を動かす |
| ホイール | 拡大縮小（Shift + ホイールで横スクロール） |
| Ctrl+Z / Ctrl+Shift+Z（Ctrl+Y） | 元に戻す / やり直す |
| Ctrl+S | プロジェクトを保存 |
| Ctrl+0 / Ctrl+1 | 全体表示 / 100% |

## 今後の予定

1. **実用**: 選択範囲（矩形・投げ縄）、レイヤーマスク、調整レイヤー、変形（拡大縮小・回転）、ぼかし・シャープ、グラデーション、図形の枠線、文字の中央揃え
2. **互換**: PSD の読み書き、大きな画像の高速化、自動保存
3. **AI**: 日本語の指示で編集（Claude が編集コマンドを組み立てる）、サムネイルの講評、背景除去（端末内で動くモデル）

## 構成

| ファイル | 役割 |
|---|---|
| `src/app.ts` | 画面・ツール・パネルの操作 |
| `src/doc.ts` | 編集中の画像（レイヤーの並び） |
| `src/layer.ts` | レイヤー、文字の描画 |
| `src/history.ts` | 元に戻す・やり直す |
| `src/compositor.ts` | レイヤーを重ねて 1 枚にする |
| `src/filters.ts` | 色調補正、塗りつぶし |
| `src/io.ts` | 開く・保存・書き出し |
